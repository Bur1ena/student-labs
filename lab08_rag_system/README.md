# Лабораторная работа №8. Построение RAG-системы

## Цель работы
Научиться проектировать и реализовывать базовую систему генерации с дополнением из внешних знаний (RAG), отделять этап поиска от этапа генерации, обеспечивать трассируемость ответа до исходных документов.

## Используемые технологии
* Python 3.10+
* Библиотеки: `openai`, `sentence-transformers`, `scikit-learn`, `pandas`, `json`
* Среда выполнения: LM Studio
* Модель эмбеддингов: `paraphrase-multilingual-MiniLM-L12-v2`
* Генеративная LLM: `qwen2.5-7b-instruct`

## Архитектура RAG-контура
1. **База знаний:** 10 документов по ИБ (формат `corpus.jsonl`).
2. **Retrieval (Поиск):** Запрос пользователя кодируется моделью эмбеддингов, затем с помощью косинусного сходства находятся top-2 наиболее релевантных документа.
3. **Prompt Construction (Формирование контекста):** Найденные документы упаковываются в блок CONTEXT с присвоением идентификаторов `[S1]`, `[S2]`.
4. **Generation (Генерация):** Модель Qwen 7B получает системную инструкцию (отвечать только по контексту, указывать источники, не выдумывать) и блок CONTEXT с вопросом. 
5. **Трассировка:** Модель возвращает ответ с указанием источников, которые реально были в контексте.

## Результаты тестирования (4 вопроса)

| Вопрос | Найденные ID (Top-2) | Ответ модели | Время (сек) |
|---|---|---|---|

| Куда сообщать об инциденте ИБ? | d07, d05 | Об инциденте информационной безопасности необходимо немедленно сообщать в службу ИБ [S1]. | 9.84 |

## Анализ результатов
1. **Точность поиска:** Во всех вопросах, на которые есть ответ в базе, поиск (Retrieval) нашел правильный документ (d01, d06, d07) и он попал на первое место.
2. **Борьба с галлюцинациями:** На вопрос про VPN-сервер (ответа на который нет в базе знаний) модель Qwen 7B четко отработала по системной инструкции и выдала фразу: *"В предоставленных источниках недостаточно информации"*. Это подтверждает, что RAG-система способна отказываться от ответа при отсутствии фактов.
3. **Трассируемость:** Модель корректно ссылается на источники `[S1]`, которые были переданы в контексте, что позволяет пользователю проверить информацию.

## Вывод
В ходе работы была успешно построена RAG-система, объединяющая семантический поиск и генеративную LLM. Эксперимент показал, что использование RAG позволяет получать точные ответы на основе внутренней базы знаний с указанием источников. Наличие строгого системного промпта и механизма отказа от ответа при отсутствии данных решает проблему галлюцинаций.
