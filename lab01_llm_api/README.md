# Лабораторная работа №1. Первое знакомство с LLM через API

## Цель работы
Освоить базовый программный цикл взаимодействия с LLM через API и научиться сравнивать модели на одинаковом наборе заданий.

## Используемые технологии
* Python 3.10+
* Библиотеки: `openai`, `pandas`
* Среда выполнения: LM Studio
* Модели: `llama-3.2-3b-instruct` и `qwen2.5-7b-instruct`

## Описание решения
Был написан скрипт `main.py`, который отправляет 5 запросов разных типов (объяснение, классификация, генерация кода, суммаризация, извлечение JSON) к локальному API LM Studio. Время выполнения каждого запроса замерялось с помощью библиотеки `time`. Результаты сохранены в файлы `results_llama.csv` и `results_qwen.csv`.

## Вывод
В ходе работы я научилась подключаться к локальной LLM через Python и замерять время ответа. 

Сравнение показало, что модель **Qwen 2.5 7B** работает медленнее (в среднем 15 секунд против 10 у Llama), но выдает **значительно более качественные и точные ответы**. 
* Llama 3B (3 миллиарда параметров) склонна к смешению языков (вставила английские и китайские слова) и иногда нарушает формат (одинарные кавычки вместо JSON).
* Qwen 7B (7 миллиардов параметров) четко следует инструкциям, пишет грамотный код и возвращает валидный JSON.

Для реальных прикладных задач (особенно в ИБ, где важна точность) лучше использовать модель Qwen 7B, несмотря на большее время генерации.
