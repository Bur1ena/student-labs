# Лабораторная работа №4. Оценка качества больших языковых моделей

## Цель работы
Освоить базовые методы количественной и качественной оценки LLM и построить воспроизводимый мини-бенчмарк для сравнения моделей.

## Используемые технологии
* Python 3.10+
* Библиотеки: `openai`, `pandas`, `scikit-learn`
* Среда выполнения: LM Studio
* Модели: `llama-3.2-3b-instruct` (3B) и `qwen2.5-7b-instruct` (7B)

## Вывод
Сравнение показало, что более крупная модель **Qwen 7B** точнее справляется с задачей (Accuracy 0.93 против 0.83) и делает меньше ложных срабатываний. Однако **Llama 3B** работает почти в два раза быстрее (3.56 сек. против 6.53 сек.) и показывает идеальную стабильность формата JSON (0 ошибок). Для систем реального времени предпочтительна Llama, для систем безопасности — Qwen 7B.
