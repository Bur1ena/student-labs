# Лабораторная работа №7. Эмбеддинги и семантический поиск

## Цель работы
Освоить построение воспроизводимого контура семантического поиска: подготовка корпуса документов → получение эмбеддингов → вычисление меры близости → выдача top-k результатов.

## Используемые технологии
* Python 3.10+
* Библиотеки: `sentence-transformers`, `scikit-learn`, `pandas`
* Модель эмбеддингов: `paraphrase-multilingual-MiniLM-L12-v2` (поддерживает русский язык, размерность 384)

## Описание эксперимента
1. Был сформирован корпус из 10 документов по теме информационной безопасности (в формате `corpus.jsonl`).
2. С помощью модели `sentence-transformers` для каждого документа был получен вектор (эмбеддинг).
3. Были заданы 4 поисковых запроса, которые **не совпадают дословно** с текстами документов (например, "что делать если украли пароль").
4. С помощью косинусного сходства (`cosine_similarity`) для каждого запроса были найдены top-3 наиболее близких документа.

Результаты сохранены в файл `results_lab7.csv`.

## Анализ результатов
Семантический поиск показал высокую эффективность. Например, на запрос *"что делать если украли пароль"* первым был найден документ `d01` (про компрометацию учётной записи), хотя слова "украли" в нём нет. Это доказывает, что модель эмбеддингов улавливает смысл, а не просто ищет совпадения слов.

На запрос *"как защитить серверную комнату"* найден документ `d10` (про серверные помещения), что также демонстрирует работу с синонимами.

## Вывод
В ходе работы я освоила построение векторного индекса и поиск по смыслу. В отличие от ключевого поиска, семантический поиск находит релевантные документы, даже если запрос сформулирован другими словами. Это критически важно для создания интеллектуальных систем поиска по документации и баз знаний.
