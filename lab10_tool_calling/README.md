# Лабораторная работа №10. Подключение внешних инструментов к LLM (Tool Calling)

## Цель работы
Освоить протокол Tool Calling (Function Calling) и реализовать минимальный безопасный слой выполнения инструментов в приложении с большой языковой моделью.

## Используемые технологии
* Python 3.10+
* Библиотеки: `openai`, `json`, `ipaddress`, `re`
* Среда выполнения: Ollama (локальный сервер на порту 11434)
* Модель: `llama3.2:3b`

## Архитектура системы
1. **LLM (Llama 3B):** Получает вопрос и решает, какой инструмент нужно вызвать.
2. **Dispatcher (Код приложения):** Проверяет имя инструмента по белому списку (allowlist) и валидирует аргументы. Никакой `eval()` или `exec()` не используется.
3. **Функции (Инструменты):** `get_incident`, `lookup_ip`, `search_knowledge_base`, `get_alert` — выполняют чтение данных и возвращают результат.

### Тесты безопасности (без LLM)
*   `dispatch("delete_database", "{}")` -> `{"error": "forbidden_tool"}`
*   `dispatch("lookup_ip", '{"ip": "bad-ip"}')` -> `{"error": "invalid_arguments"}`
*   `dispatch("get_incident", '{"incident_id":"INC-101","admin":true}')` -> `{"error": "invalid_arguments"}`
*   `dispatch("get_incident", '{"incident_id":"INC-999"}')` -> `{"data": {"error": "not_found"}}`

## Анализ результатов
1. **Ограничения модели Llama 3B:** Маленькая модель (3B) показала низкую надежность. Она часто галлюцинирует, смешивает языки (вьетнамский, китайский) и на приветствие (T4) ошибочно вызывает инструмент. На запрос удаления (T6) она попыталась сгенерировать JSON-код для вызова функции, но dispatcher не выполнил его.
2. **Безопасность:** Все опасные действия были заблокированы на уровне приложения. Dispatcher строго проверяет имя инструмента и аргументы, не позволяя модели выйти за рамки разрешенных функций.
3. **Индивидуальное задание:** Реализован дополнительный инструмент `get_alert` для получения информации об учебных алертах. Проверена его работа и валидация аргументов.

## Вывод
В ходе работы был реализован безопасный слой Tool Calling. Несмотря на ограничения маленькой модели (Llama 3B), архитектура приложения (разделение ответственности: LLM предлагает, приложение проверяет и выполняет) показала свою эффективность. Dispatcher заблокировал все попытки несанкционированных действий. Для реальных задач Tool Calling рекомендуется использовать более крупные модели (например, Qwen 7B), которые лучше понимают инструкции и не галлюцинируют.
