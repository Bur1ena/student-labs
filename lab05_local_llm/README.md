# Лабораторная работа №5. Развёртывание и исследование локальной LLM

## Цель работы
Получить практические навыки развёртывания большой языковой модели на локальном компьютере, подключения к ней через API, измерения требований к вычислительным ресурсам и производительности.

## Используемые технологии
* Python 3.10+
* Библиотеки: `requests`, `json`
* Среда выполнения: Ollama (локальный сервер на порту 11434)
* Модель: `llama3.2:3b` (3B параметров, квантование Q4_K_M)

## Анализ ресурсов
Во время работы скрипта процесс `ollama.exe` занимал около **2.5 ГБ** оперативной памяти. Модель работала на CPU (без использования GPU), так как ноутбук не имеет дискретной видеокарты с достаточным объемом VRAM. Средняя скорость генерации составила около 5–10 токенов в секунду.

## Вывод
Локальный запуск через Ollama позволяет работать с LLM без интернета и без передачи данных в облако, что важно для конфиденциальности. Однако модель Llama 3B (3 млрд параметров) показала низкое качество на сложных задачах: она часто ошибается в классификации ИБ, пишет неверный код и смешивает языки. Для реальных задач ИБ требуется использовать более крупные модели (7B+), которые можно запустить локально при наличии достаточного объема оперативной памяти (16+ ГБ).
